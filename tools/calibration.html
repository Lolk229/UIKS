🎯 Floor Plan Calibration Tool

Инструкция:

  1. Загрузите PDF или PNG файл планировки (слева)
  2. Загрузите соответствующий SVG файл карты (справа)
  3. Кликните на 4 соответствующие точки на обоих планах (углы здания или другие ориентиры)
  4. Проверьте правильность выбора точек
  5. Нажмите "Сохранить калибровку" для экспорта JSON файла
  6. Поместите скачанный файл в директорию plans/calibration/
