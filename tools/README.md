# Floor Plan Recognition System - Tools Documentation

Система автоматического распознавания планировок этажей из PDF файлов и генерации координат для аудиторий, коридоров и дверей.

## 🚀 Быстрый старт

```bash
# 1. Установить зависимости
npm install

# 2. Извлечь изображение из PDF
node scripts/generateFromFloorPlan.js --pdf plans/floor3.pdf --extract --floor 3

# 3. Распознать номера аудиторий
node scripts/generateFromFloorPlan.js --pdf plans/floor3.pdf --ocr --floor 3

# 4. Калибровать координаты
# Открыть tools/calibration.html в браузере

# 5. Сгенерировать точки
node scripts/generateFromFloorPlan.js --floor 3 --generate-all --dry-run

# 6. Проверить результаты
# Открыть tools/preview.html в браузере

# 7. Применить изменения
node scripts/generateFromFloorPlan.js --floor 3 --apply
```

## 📦 Установка зависимостей

Перед началом работы необходимо установить все зависимости:

```bash
npm install
```

Устанавливаемые пакеты:
- **pdf-parse** (^1.1.1) - парсинг PDF файлов
- **pdfjs-dist** (^3.11.174) - рендеринг PDF в изображения
- **tesseract.js** (^5.0.0) - OCR распознавание текста
- **canvas** (^2.11.2) - работа с canvas в Node.js
- **jimp** (^0.22.10) - обработка изображений

### Требования к системе

- Node.js >= 16.x
- NPM >= 7.x
- 2GB свободной оперативной памяти (для OCR)
- Современный браузер (Chrome/Edge/Firefox) для веб-инструментов

## 📖 Пошаговая инструкция

### Шаг 1: Подготовка PDF файла

Поместите PDF файл планировки этажа в директорию `plans/`:

```
plans/
  └── floor3.pdf
```

**Требования к PDF:**
- Первая страница содержит планировку
- Текст должен быть читаемым (не скан плохого качества)
- Формат A3 или A4
- Номера аудиторий должны быть подписаны на плане

### Шаг 2: Извлечение изображения

Конвертируем PDF в PNG изображение высокого разрешения (300 DPI):

```bash
node scripts/generateFromFloorPlan.js --pdf plans/floor3.pdf --extract --floor 3
```

**Результат:**
```
plans/
  └── extracted/
      └── floor3.png
```

**Что происходит:**
- PDF конвертируется в PNG с разрешением 300 DPI
- Используется только первая страница
- Изображение сохраняется для последующего OCR

### Шаг 3: OCR распознавание

Распознаём номера аудиторий с помощью Tesseract.js:

```bash
node scripts/generateFromFloorPlan.js --pdf plans/floor3.pdf --ocr --floor 3
```

**Процесс:**
1. Загружается изображение `floor3.png`
2. Запускается OCR с языками `rus+eng`
3. Ищутся паттерны номеров аудиторий: `Б3-1`, `Б3-2`, etc.
4. Исключаются служебные помещения (WC, лестницы и т.д.)
5. Сохраняются координаты каждой найденной аудитории

**Результат:**
```
plans/
  └── calibration/
      └── floor3-rooms.json
```

**Содержимое floor3-rooms.json:**
```json
{
  "rooms": [
    {
      "id": "Б3-1",
      "bbox": {
        "x": 150,
        "y": 200,
        "width": 100,
        "height": 80
      },
      "center": {
        "x": 200,
        "y": 240
      },
      "text": "Б3-1",
      "confidence": 0.95
    }
  ]
}
```

**Время выполнения:** 2-5 минут в зависимости от размера изображения

### Шаг 4: Калибровка координат

Калибровка необходима для преобразования координат из PDF в систему координат SVG карты.

**Открыть:** `tools/calibration.html` в браузере

**Процесс:**

1. **Загрузить файлы:**
   - PDF План (слева): выбрать `plans/extracted/floor3.png`
   - SVG Карта (справа): выбрать `images/Этаж3.svg`

2. **Выбрать 4 опорные точки:**
   - Кликнуть на характерную точку на PDF плане (например, угол здания)
   - Кликнуть на ту же точку на SVG карте
   - Повторить для 4 точек

   **Рекомендуемые опорные точки:**
   - Углы здания
   - Пересечения коридоров
   - Центры лестничных клеток
   - Любые явно видимые ориентиры на обоих планах

3. **Проверить правильность:**
   - Все 4 точки должны быть отмечены на обоих планах
   - Визуально проверить соответствие точек

4. **Сохранить калибровку:**
   - Нажать "Сохранить калибровку"
   - Ввести номер этажа (например, 3)
   - Скачать файл `floor3-calibration.json`
   - Поместить файл в `plans/calibration/`

**Результат:**
```
plans/
  └── calibration/
      └── floor3-calibration.json
```

**Содержимое floor3-calibration.json:**
```json
{
  "floor": 3,
  "pdfPoints": [
    {"x": 100, "y": 100},
    {"x": 800, "y": 100},
    {"x": 800, "y": 600},
    {"x": 100, "y": 600}
  ],
  "svgPoints": [
    {"x": 500, "y": 500},
    {"x": 2500, "y": 500},
    {"x": 2500, "y": 3500},
    {"x": 500, "y": 3500}
  ],
  "timestamp": "2024-01-15T10:30:00.000Z"
}
```

### Шаг 5: Генерация точек (Dry Run)

Генерируем координаты для всех распознанных аудиторий:

```bash
node scripts/generateFromFloorPlan.js --floor 3 --generate-all --dry-run
```

**Что происходит:**
1. Загружаются распознанные аудитории из `floor3-rooms.json`
2. Загружается калибровка из `floor3-calibration.json`
3. Вычисляется матрица аффинного преобразования
4. Для каждой аудитории:
   - Берётся центр bbox
   - Координаты трансформируются из PDF в SVG систему
   - Создаётся объект точки в формате config.js

**Вывод в консоль:**
```
Generating points for floor 3...

=== Generation Report ===
Floor: 3
Rooms generated: 47
Corridor nodes: 0 (not implemented yet)
Doors generated: 0 (not implemented yet)

Warnings:
  - Room Б3-15: coordinates may be outside viewBox [4200, 1500]
  - Room Б3-34: duplicate coordinates with Б3-35

✓ Saved generated points to: plans/calibration/floor3-generated.json
```

**Результат:**
```
plans/
  └── calibration/
      └── floor3-generated.json
```

### Шаг 6: Визуальная проверка

Перед применением изменений рекомендуется визуально проверить результаты.

**Открыть:** `tools/preview.html` в браузере

**Процесс:**

1. **Загрузить файлы:**
   - SVG Map File: выбрать `images/Этаж3.svg`
   - Generated Points: выбрать `plans/calibration/floor3-generated.json`
   - Config.js File (опционально): выбрать `js/config.js` для сравнения

2. **Проверить точки:**
   - Новые точки отображаются зелёным цветом
   - Существующие точки - синим
   - Конфликты (дубликаты) - красным

3. **Использовать фильтры:**
   - Show Rooms / Corridors / Doors
   - Show Existing Points / New Points

4. **Кликнуть на точку:**
   - Увидеть детали: ID, тип, координаты
   - Проверить корректность позиции

5. **Использовать Zoom:**
   - Увеличить/уменьшить для детального просмотра
   - Проверить что все точки на своих местах

**Если обнаружены проблемы:**
- Неправильные координаты → повторить калибровку (Шаг 4)
- Пропущенные аудитории → проверить OCR результаты
- Лишние точки → отредактировать `floor3-rooms.json` вручную

### Шаг 7: Применение изменений

Если всё выглядит корректно, применяем изменения к `config.js`:

```bash
node scripts/generateFromFloorPlan.js --floor 3 --apply
```

**Что происходит:**
1. Создаётся резервная копия `config.js.backup.{timestamp}`
2. Загружаются сгенерированные точки из `floor3-generated.json`
3. Точки добавляются в массив `points[3]` в config.js
4. Файл сохраняется с правильным форматированием

**Вывод:**
```
Created backup: js/config.js.backup.1705315800000
Adding new floor 3...
✓ Successfully updated config.js
  Added 47 rooms for floor 3
```

**Результат:**
```javascript
// В js/config.js
points: {
  1: [...],
  2: [...],
  3: [
    { id: "Б3-1", name: "Б3-1", coords: [680, 1535], type: "room" },
    { id: "Б3-2", name: "Б3-2", coords: [760, 1535], type: "room" },
    // ... остальные точки
  ],
  // ...
}
```

## 🛠 Описание инструментов

### 1. generateFromFloorPlan.js

Главный скрипт для обработки планировок.

**Команды:**

```bash
# Извлечение изображения
node scripts/generateFromFloorPlan.js --pdf FILE --extract [--floor N]

# OCR распознавание
node scripts/generateFromFloorPlan.js --pdf FILE --ocr --floor N

# Генерация точек
node scripts/generateFromFloorPlan.js --floor N --generate-all [--dry-run]

# Применение изменений
node scripts/generateFromFloorPlan.js --floor N --apply
```

**Параметры:**
- `--pdf FILE` - путь к PDF файлу
- `--extract` - извлечь изображение из PDF
- `--ocr` - выполнить OCR распознавание
- `--floor N` - номер этажа
- `--generate-all` - сгенерировать все точки
- `--dry-run` - режим предпросмотра без применения
- `--apply` - применить изменения к config.js

**Алгоритм трансформации координат:**

Используется аффинное преобразование (affine transformation):
```
x' = a*x + b*y + c
y' = d*x + e*y + f
```

Где `(x, y)` - координаты в PDF, `(x', y')` - координаты в SVG.

Матрица трансформации вычисляется на основе 4 опорных точек методом наименьших квадратов.

### 2. calibration.html

Веб-интерфейс для калибровки координат.

**Функции:**
- Загрузка PDF/PNG и SVG файлов
- Интерактивный выбор опорных точек
- Визуальные маркеры на обоих планах
- Zoom in/out для точности
- Экспорт JSON калибровки

**Поддерживаемые форматы:**
- PDF (конвертируется в PNG через PDF.js)
- PNG, JPG (для PDF плана)
- SVG (для карты)

**Технологии:**
- PDF.js для рендеринга PDF
- Vanilla JavaScript (без фреймворков)
- LocalStorage для сохранения прогресса

### 3. preview.html

Инструмент визуализации и проверки точек.

**Функции:**
- Наложение точек на SVG карту
- Цветовая индикация (новые/существующие/конфликты)
- Фильтры по типам точек
- Детали точки по клику
- Статистика и отчёт
- Zoom и Pan

**Легенда:**
- 🟢 Зелёный - новые точки
- 🔵 Синий - существующие точки
- 🔴 Красный - конфликты (дубликаты)

## 🔧 Troubleshooting

### Проблема: OCR не распознаёт аудитории

**Причины:**
- Низкое качество PDF
- Мелкий шрифт на плане
- Нестандартные обозначения

**Решение:**
1. Проверить качество `plans/extracted/floor3.png`
2. Увеличить DPI при извлечении (изменить код)
3. Вручную отредактировать `floor3-rooms.json`

### Проблема: Неправильные координаты после трансформации

**Причины:**
- Неточная калибровка
- Недостаточное количество опорных точек
- Ошибка в выборе точек

**Решение:**
1. Повторить калибровку с более точными точками
2. Выбрать точки на всех углах здания
3. Проверить что PDF и SVG имеют одинаковую ориентацию

### Проблема: Canvas/PDF.js не работает в Node.js

**Причины:**
- Проблемы с установкой canvas пакета
- Отсутствие системных зависимостей

**Решение (Ubuntu/Debian):**
```bash
sudo apt-get install build-essential libcairo2-dev libpango1.0-dev libjpeg-dev libgif-dev librsvg2-dev
npm install canvas
```

**Решение (macOS):**
```bash
brew install pkg-config cairo pango libpng jpeg giflib librsvg
npm install canvas
```

**Решение (Windows):**
- Установить Windows Build Tools
- Использовать GTK2

### Проблема: Tesseract.js долго работает

**Причины:**
- Большое разрешение изображения
- Медленный процессор

**Решение:**
1. Уменьшить DPI в настройках извлечения (с 300 до 200)
2. Предварительно обрезать изображение до нужной области
3. Использовать более мощную машину

### Проблема: Конфликты координат

**Причины:**
- Дубликаты в OCR результатах
- Несколько аудиторий в одном месте на плане

**Решение:**
1. Проверить `floor3-rooms.json` на дубликаты
2. Вручную удалить лишние записи
3. Скорректировать координаты в `floor3-generated.json`

## 📊 Критерии качества

✅ **Успешная обработка:**
- OCR распознаёт минимум 90% аудиторий
- Погрешность координат < 5%
- Нет дубликатов
- Все точки в пределах viewBox

⚠️ **Требует внимания:**
- OCR распознаёт 70-90% аудиторий → ручная корректировка
- Погрешность 5-10% → повторная калибровка
- Единичные дубликаты → ручное удаление

❌ **Неудовлетворительно:**
- OCR < 70% → проблема с качеством PDF
- Погрешность > 10% → неправильная калибровка
- Многочисленные дубликаты → ошибка в алгоритме

## 📝 Примечания

1. **Резервные копии:** Скрипт всегда создаёт backup перед изменением config.js
2. **Формат координат:** В config.js используется формат `[y, x]`, а не `[x, y]`
3. **Валидация:** Проверяйте результаты в preview.html перед применением
4. **Коридоры и двери:** В текущей версии генерируются только rooms (P0)
5. **Batch processing:** Пока не реализован, обрабатывается по одному этажу
