# Автоматическая генерация дверей для аудиторий второго этажа

## Выполненные задачи

✅ **Создан скрипт `scripts/generateDoors.js`**
- Автоматический анализ осей коридоров
- Генерация координат дверей для аудиторий без дверей
- Поддержка режимов --dry-run и --apply
- Детальный отчёт о результатах работы

✅ **Реализован алгоритм генерации**
1. Группировка corridor-узлов в оси (horizontal/vertical)
2. Фильтрация только крупных осей (≥10 точек)
3. Для каждой аудитории без двери:
   - Поиск ближайшей оси коридора (perpDist ≤ 60px)
   - Размещение двери на 60% пути от аудитории к оси
4. Валидация и отчёт

✅ **Применены изменения**
- **57 дверей** добавлено для этажа 2
- Всего на этаже 2: **91 дверь** (34 существующих + 57 новых)
- Создана резервная копия config.backup.js

✅ **Документация**
- Подробный README.md в директории scripts/
- Комментарии в коде
- Примеры использования
